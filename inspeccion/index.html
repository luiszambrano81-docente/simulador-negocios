Conexión con Supabase

Esta app ya viene conectada por defecto a la base de datos central — Julio y Lorena no necesitan tocar nada aquí. Esta sección es solo para ti, por si en el futuro cambias de proyecto en Supabase.

Cómo obtener estos datos (una sola vez)
  1. Crea un proyecto gratuito en supabase.com.
  2. Ve a SQL Editor (icono de base de datos), pega el archivo supabase_setup.sql que te compartí y dale a Run. Esto crea la tabla de registros y el almacén de fotos automáticamente.
  3. Ve a Project Settings → API.
  4. Copia el Project URL y la llave anon public, y pégalos arriba.
